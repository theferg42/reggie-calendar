Vault Calendar

Vault Calendar is a private, single-user tool. It adds and updates events on one Google Calendar that it created itself, called "Reggie", after the owner approves each event.

It asks Google for one permission only: to manage calendars and events that this app created (calendar.app.created). It cannot see or change any other calendar.

It is not offered to the public, and there is nothing to sign up for.
